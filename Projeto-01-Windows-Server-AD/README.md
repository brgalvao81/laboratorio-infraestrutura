# Projeto 01: Windows Server e Active Directory

Laboratório em máquina virtual para praticar o que as vagas de suporte e help desk pedem em ambiente Windows: servidor, Active Directory, usuários, senhas, acessos, DNS e DHCP.

## Ambiente
- Notebook com Windows 11 e VirtualBox
- Servidor `SRV01`: Windows Server 2025 Standard Evaluation (Desktop Experience)
- Domínio: `empresa.local`
